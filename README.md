# Agentic AI Learning - 30 Day Expert Plan

A comprehensive 30-day structured learning path to become an expert in building Agentic AI systems.

## Overview

This program is designed to take you from foundational concepts to advanced implementation of AI agents in 30 days. Each day builds upon previous knowledge with hands-on exercises and real-world applications.

## Glossary

- **Agent**: An AI system that can perceive its environment, make decisions, and take actions to achieve specific goals
- **LLM (Large Language Model)**: Foundation models like GPT-4, Claude, or Llama that power intelligent agents
- **Tool Use**: The ability of an agent to call external functions, APIs, or services
- **Function Calling**: Structured way for LLMs to invoke predefined functions with parameters
- **Prompt Engineering**: The art of crafting effective instructions for LLMs
- **RAG (Retrieval Augmented Generation)**: Technique to enhance LLM responses with external knowledge
- **Memory Systems**: Mechanisms for agents to store and recall information across interactions
- **Planning**: The process by which agents break down complex tasks into steps
- **ReAct**: Reasoning and Acting framework for agents
- **Multi-Agent Systems**: Multiple AI agents working together to solve complex problems
- **Orchestration**: Coordinating multiple agents or tools to accomplish tasks
- **Chain-of-Thought (CoT)**: Prompting technique that encourages step-by-step reasoning
- **Embeddings**: Vector representations of text used for semantic search
- **Vector Database**: Specialized database for storing and querying embeddings
- **Context Window**: The amount of text an LLM can process at once
- **Fine-tuning**: Training a model on specific data to improve performance
- **Evaluation**: Measuring agent performance and reliability
- **Hallucination**: When LLMs generate false or unsupported information

## Prerequisites

- Python programming experience
- Basic understanding of APIs and REST
- Familiarity with command line tools
- Git/GitHub knowledge
- OpenAI, Anthropic, or similar LLM API access

## Learning Approach

Each day includes:
- **Theoretical Concepts**: Core ideas and principles
- **Hands-On Exercises**: Practical coding tasks
- **Resources**: Links to papers, documentation, and tutorials
- **Daily Challenge**: A project to reinforce learning
- **Reflection Questions**: To deepen understanding

## Recommended Tools & Frameworks

- **LLM Providers**: OpenAI (GPT-4), Anthropic (Claude), Google (Gemini)
- **Agent Frameworks**: LangChain, LangGraph, AutoGen, CrewAI, Semantic Kernel
- **Vector DBs**: Pinecone, Weaviate, Chroma, Qdrant
- **Development**: Python, TypeScript/JavaScript
- **Tools**: Jupyter Notebooks, VSCode, Git
